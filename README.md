# KIS OS funnels (draft)

Static VSL funnel and quiz funnel concepts for KIS OS. Draft for review; bracketed items are placeholders.

- VSL funnel: `vsl/` > `book/` > `confirmed/` (below the fit line: `not-yet/`)
- Quiz funnel: `quiz/` > `quiz/result/?type=...`
- Copy for review: `copy/`

No backend: forms store answers in sessionStorage only. Swap the `// GHL:` stubs for real GHL forms and calendar at build.
